# Keyboard Shortcuts

Chau7 provides extensive keyboard shortcuts for efficient navigation.

## Customizing Shortcuts

Open the Keyboard Shortcuts editor from:
- **⌘/**: Keyboard Shortcuts
- Command Palette: **⇧⌘P** → "Keyboard Shortcuts"
- Settings → Input → Keyboard Shortcuts

Click any shortcut to record a new key combination.

## Default Shortcuts

### Window & Tabs
- **⌘N**: New Window
- **⌘T**: New Tab
- **⌘W**: Close Tab
- **⇧⌘W**: Close Window
- **⌘1-9**: Switch to Tab

### Edit
- **⌘C**: Copy (or interrupt if no selection)
- **⌘V**: Paste
- **⌥⌘V**: Paste Escaped
- **⌘F**: Find
- **⌘G**: Find Next
- **⇧⌘G**: Find Previous

### View
- **⌘=**: Zoom In
- **⌘-**: Zoom Out
- **⌘0**: Reset Zoom
- **⌘K**: Clear Screen
- **⇧⌘K**: Clear Scrollback
- **⌃⌘F**: Full Screen

### Tools
- **⇧⌘P**: Command Palette
- **⇧⌘O**: SSH Connections
- **⌘;**: Snippets
- **⌥⌘L**: Debug Console
