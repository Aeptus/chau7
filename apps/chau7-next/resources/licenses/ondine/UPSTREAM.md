# Ondine compiler

Source: https://github.com/wevm/ondine

Pinned revision: `6a1586e5af980e67c104239593ae931837157b8b`.

Chau7 links the unmodified Rust `crates/compiler` package as a pinned Cargo Git dependency. It has no runtime dependencies and includes all diagram types. The native SVG theme adapter is Chau7-owned code.

Ondine includes MIT-licensed code derived from Pele (https://github.com/obsidianmd/pele). Both upstream license files are preserved here and copied into packaged apps. Pele itself is not linked or executed.
