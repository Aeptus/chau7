# Terminal

Swift: `apps/chau7-macos/Sources/Chau7/Terminal/` (17 files, 5,939 lines)
Swift tests: `Terminal/TerminalSessionModelTests`, `Terminal/CommandBlockTests`, `Terminal/AIDetectionStateTests`, `Terminal/TerminalNormalizerTests`, `Terminal/SensitiveInputGuardTests`, `CrossCutting/ShellLaunchEnvironmentTests`
Wave: 1
Depends on: RustBackend (shared `chau7_terminal` emulator, already linked by Chau7 Next)

One `TerminalSessionModel` per terminal pane: it picks and launches the shell
with Chau7's environment and wrapper startup files, follows the shell (directory,
git, prompt, running command, exit), tracks what the user types (history, AI
tool detection, dangerous commands), and offers find-in-scrollback, bookmarks
and command blocks. It is also where AI tool sessions are detected, logged and
reported to notifications, telemetry and remote control.

## Notes

- **Startup files.** Swift writes `.zshrc`, `.bashrc` and `.config/fish/config.fish`
  to `$TMPDIR/smartoverlay/` once at launch (`preInitialize`). zsh gets
  `ZDOTDIR`, fish gets `XDG_CONFIG_HOME`, bash gets `--rcfile` plus `BASH_ENV`.
  Chau7 Next uses `~/.chau7-next/shell/` and, for bash, only `PROMPT_COMMAND`
  and `PS0` from the environment; a user `.bashrc` that assigns
  `PROMPT_COMMAND` outright removes the hooks (check when finishing TRM-032).
- **Markers.** Swift's own scripts emit only OSC 7 and `OSC 9;chau7;exit=N`.
  The OSC 133 handling (TRM-034) reacts when the user's prompt framework emits
  133, and then switches off the heuristics of TRM-035. Chau7 Next always
  emits 133 A, C and D, so TRM-035 only matters for shells without our hooks
  (nu, custom shells).
- **Directory.** Chau7 Next follows OSC 7 (also from ssh and subshells) and
  typed `cd` lines like Swift; it reads the cwd from the process table only
  while the shell has sent no OSC 7 (shells without our hooks).
- **Sensitive input.** Swift treats a typed line as secret when the PTY has
  echo off. Line editors (readline, zsh ZLE) turn echo off while editing, so
  every command looked secret; Chau7 Next requires echo off in canonical mode
  (password prompts) instead (`password_input_on_fd`).
- **Startup files (Chau7 Next).** `~/.chau7-next/shell/`: zsh `ZDOTDIR`,
  bash `--rcfile bash/.bashrc` (hooks appended to `PROMPT_COMMAND` after the
  user's files, no `BASH_ENV`, which Swift sets and which would run the
  startup command in every bash script), fish `XDG_CONFIG_HOME`. The hooks
  emit OSC 133 B and C before each command, D with the exit code, OSC 7 and A
  at each prompt. `TERM_PROGRAM` stays `Chau7Next` so tools and
  `inherited_cleanup` can tell the apps apart.
- **Env vars read:** `CHAU7_IDLE_SECONDS` (default 3), `CHAU7_COMMAND_FALLBACK_SECONDS`,
  `CHAU7_CLEAR_ON_LAUNCH`, `CHAU7_REMOTE_OUTPUT_BATCH`, `CHAU7_PTY_DUMP`,
  `CHAU7_TRACE_PTY`, `CHAU7_PTY_DUMP_PATH`, `CHAU7_PTY_DUMP_MAX_BYTES`.
- **Dormant Swift code** (no user-visible effect today, kept as rows only when
  a setting exposes it): `LineTimestampTracker` and `TimestampOverlayView` are
  never instantiated although the "line timestamps" setting exists (TRM-058);
  `maybeClearOnLaunch` (Ctrl+L on first attach) has no caller;
  `TerminalLineView`, `TerminalLinesView`, `ScrollableTerminalView` and
  `HistoryEntryRow` in `Views/TerminalLineView.swift` are unused;
  `scheduleShellIntegration`/`applyShellIntegration` are no-ops.
- **n/a rows.** TRM-009: a Chau7 Next session owns its PTY from creation, so
  writes never precede the view. TRM-063: GPUI only paints visible views.
  TRM-064: GPUI renders on the GPU (PARITY.md "Performance: replaced").
- **Waiting-input patterns** (TRM-042): `Yes/No`, `[y/N]`, `[Y/n]`, `(y/n)`,
  `Allow?`, `Approve?`, `Continue?`, `Proceed?`, `Permission`, `> `, `? `,
  `Enter your`, `Type your`, `waiting for` (case-insensitive, only while an AI
  tool is active and the status is running).
- **Events this module produces** (see Events.md): `terminal_session`
  finished/failed on shell exit (TRM-008), `waiting_input` fallback (TRM-043),

  `directory_changed`, `git_branch_changed`, `long_running` and output pattern
  matches.

TRM-066 actual selection evidence: all UI/MCP selection callers share `clipboard_selection`. The same native Alacritty backend as current Swift reconstructs soft wraps and row padding. Six pure Swift policy regressions preserve normal bytes, CRLF/Unicode boundaries, paths and argument whitespace; three real headless native selection regressions prove soft-wrap spaces, hard-wrapped paths/arguments and alternate-screen TUIs without detected AI.
