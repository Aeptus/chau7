Depends on: Terminal (shell integration command events), Settings; DataExplorer, Analytics, MCP and Repository read from it

Keeps a searchable record of the commands run in the terminal (SQLite, with directory, exit code and duration) with settings for size, export, import and cleanup. It also parses the session history files written by Claude Code and Codex, records terminal sessions for replay, and provides the generic file tailer that the AI and monitoring features use to follow log files live.

## Notes

- HIS-001: in the Swift sources nothing calls `PersistentHistoryStore.insert` or `insertSync` except `importJSON`, so the SQLite store is only filled by imports today, even though Settings, DataExplorer, Analytics, MCP and repo stats read it. Chau7 Next does record every command, through its shell hooks, as `time<TAB>dir<TAB>command` in `history.tsv` in its data root; it has no exit code, duration, tab or shell column. When porting, record from the OSC 133 C/D events (exit code and duration are already known in `terminal/session.rs`) into a store in the Chau7 Next data root; never write the Swift `history.db`.
- HIS-003: the Chau7 Next picker loads the latest 500 unique commands (duplicates collapsed to their latest use) and filters them as you type; it now reads the Chau7 Next history database and shows exit mark, directory, duration and age, with Recent / Most used and This folder toggles.
- HIS-010: in Chau7 Next arrow keys go to the shell, which uses its own history. Porting this row means intercepting arrows the way `RustTerminalView` does, and reusing the password-prompt (echo off) and secret filters (`SensitiveInputGuard`).
- HIS-012/014: these are inputs for the idle monitor (Monitoring, MON-006) and the history notification triggers (Notifications). Swift reads `~/.claude/history.jsonl` and `~/.codex/history.jsonl`; both apps may read them (DUAL-SHIP.md section 3).
- HIS-015: `TimelineScrubberView` takes a `SessionRecorder` but no Swift view constructs it, so recording has no entry point in the UI yet. Frame format: see `SessionRecorder.encodeFrames` (event type byte per frame).
- HIS-016: plumbing, but AIX-011, MON-001 and MON-006 need it; one Rust implementation should serve all three. Claude hook events use a 250 ms interval and PTY logs an 8 MB buffer.
- SQLite schema (for an import from the Swift app): table `history(id, command, directory, exit_code, shell, tab_id, session_id, timestamp REAL, duration REAL)` with indexes on timestamp, command and directory.
- Overlapping rows in other inventories (update both when porting): HIS-007/008/009 with SET-132; HIS-010 with TRM-038 and KBD-018.
