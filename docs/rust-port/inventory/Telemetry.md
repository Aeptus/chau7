# Telemetry

Swift: `apps/chau7-macos/Sources/Chau7/Telemetry/` (5 files, 2041 lines), plus `Chau7Core/Telemetry/` (`TelemetryRun.swift`, `TelemetryTurn.swift`, `TokenMetrics.swift`, `RunContentProvider.swift`, `ClaudeTranscriptUsageParser.swift`, `CodexRolloutParser.swift`, `TelemetryMetricsSanitizer.swift`, `RemoteClientTelemetryEvent.swift`)
Swift tests: `Telemetry/ClaudeTranscriptParserTests`, `Telemetry/CodexRolloutParserTests`, `Telemetry/TelemetryMetricsSanitizerTests`, `Remote/RemoteClientTelemetryEventTests`
Wave: 3
Depends on: Terminal (AI run start and end, PTY log, buffer snapshot), AI (provider detection, session IDs from resume commands and hooks). Consumers: MCP (`run_*` and `session_*` tools), Overlay (hover card), Repository (repo stats), DataExplorer, Debug, Remote.

Local-only record of AI coding sessions ("runs"). Each time an AI CLI (Claude Code, Codex, ...) runs in a tab, Chau7 stores a run with provider, model, cwd, repo, timing and exit status, then reads the tool's own transcript files to add turns, tool calls and token counts. Nothing is sent over the network and there is no opt-in or opt-out setting: recording is always on and stays in a SQLite file in the user's home.

## Notes

**What is collected, where it goes.** Per AI run: run ID, AI session ID, tab identifier, provider, model, cwd, repo path, start/end, duration, exit status, token counts (input, cached input, output, reasoning), cost (only when a source reports it), token/cost source and state, turn count, tags, raw transcript reference (a path, `pty_log` or `terminal_buffer`), error message. Per turn: role, full content text, per-turn tokens, timestamp. Per tool call: name, arguments, result, status. From the iPhone: connection and approval events. Everything is written to `~/.chau7/telemetry/runs.db` only. There is no network upload, no crash reporter and no analytics SDK in the Swift sources, and no setting to turn recording off. Transcript text (including tool results) is stored in full, which matters for privacy text in Chau7 Next.

**Chau7 Next isolation.** Use `~/.chau7-next/telemetry/runs.db` (add to `DataRoot`). `~/.claude/projects`, `~/.codex/state_5.sqlite` and `~/.codex/sessions` are read only and can be read by both apps (open the Codex SQLite file read-only).

**Schema** (`TelemetryStore.createTables`, `schema_version` = 1):
- `runs(run_id PK, session_id, tab_id, provider NOT NULL, model, cwd NOT NULL, repo_path, started_at NOT NULL, ended_at, duration_ms, exit_status, total_input_tokens, total_cached_input_tokens, total_output_tokens, total_reasoning_output_tokens, cost_usd, token_usage_source, token_usage_state, cost_source, cost_state, turn_count DEFAULT 0, tags, metadata, raw_transcript_ref, parent_run_id, error_message, created_at)`; indexes on session_id, repo_path, provider, started_at, tab_id.
- `turns(turn_id PK, run_id FK cascade, turn_index, role, content, input_tokens, cached_input_tokens, output_tokens, reasoning_output_tokens, tool_calls, timestamp, duration_ms)`.
- `tool_calls(call_id PK, run_id FK cascade, turn_id FK cascade, tool_name, arguments, result, status, duration_ms, call_index)`.
- `remote_client_events(event_id PK, source, device_id, device_name, app_version, session_id, event_type, status, tab_id, tab_title, message, metadata, timestamp)`.
Dates are ISO 8601 strings with fractional seconds. Enum values: state `complete|estimated|missing|invalid`; token source `proxy|transcriptDelta|transcriptSnapshot|providerEstimate|unknown`; cost source `observed|estimated|unavailable`. Run end uses UPDATE plus inserts in one transaction, never `INSERT OR REPLACE` (that would cascade-delete children).

**Tab identity.** The recorder keys runs by the session's `tabIdentifier`. The hover card looks runs up with the OverlayTab UUID string and only checks the single most recent run; check which identifier is right before porting TEL-011 (`TerminalControlService` has a comment saying the recorder does not use the OverlayTab UUID).

**Remote client event JSON** (`REMOTE_TELEMETRY` payload): `id, source ("ios"), device_id, device_name, app_version, session_id, event_type, status, tab_id, tab_title, message, metadata {string: string}, timestamp`; `timestamp` is Swift's default Date encoding (seconds since 2001-01-01). Event types: `connect_requested, pair_request_sent, session_encrypted, disconnected, reconnect_scheduled, tab_switched, approval_received, approval_responded, notification_opened, protected_action_prompted, protected_action_submitted, error_received, frame_decode_failed, frame_decrypt_failed, send_failed`.

**Providers.** Content providers are chosen by provider name: contains "claude" or equals "anthropic" -> Claude; Codex provider when it contains "codex" or "openai", or equals "gpt". Other AI tools get only lifecycle data plus the fallback transcript. Claude cost is never computed (marked `unavailable`).
