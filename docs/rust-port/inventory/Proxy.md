# Proxy

Swift: `apps/chau7-macos/Sources/Chau7/Proxy/` (7 files, 2435 lines), plus `Settings/Views/ProxySettingsView.swift`, the env injection in `Terminal/Session/TerminalSessionModel.swift` (`buildEnvironment`), task UI wiring in `Overlay/OverlayTabsModel.swift` and `Overlay/Chau7OverlayView.swift`
Swift tests: `Proxy/APICallEventTests` (also `AIEventNotificationTests`, `AIEventSourceExtendedTests` in the same file)
Wave: 3
Depends on: Settings, Terminal (shell environment), Overlay (task banners), App (unified AI event stream), Debug (stats view). Runtime dependency: the Go proxy `apps/chau7-macos/chau7-proxy` (cross-platform, no CGO).

"API Analytics": a local HTTP proxy that CLI tools (Claude Code, Codex, Gemini CLI, Aider...) are pointed at through environment variables. It forwards every LLM API call unchanged (auth headers included) and records provider, model, tokens, latency, cost and status into a SQLite database, and notifies the app of each call over a Unix socket. The proxy also groups calls into "tasks" per tab and asks the user to confirm and grade them.

## Notes

**Files and paths** (Swift, all under `RuntimeIsolation.appSupportDirectory(named: "Chau7")/Proxy/`): `analytics.db`, `proxy.sock`, `proxy-cert.pem`, `proxy-key.pem`. Chau7 Next must use `~/Library/Application Support/Chau7 Next/Proxy/` and a different default port, because both apps would otherwise bind 127.0.0.1:18080/18081 (the second proxy fails to start and its shells would talk to the other app's proxy). `proxy.sock` is already on the forbidden-string list in `data_root.rs`. `chau7_next_core/src/shell_env.rs` already removes `ANTHROPIC_BASE_URL`, `OPENAI_BASE_URL` and `GOOGLE_GEMINI_BASE_URL` inherited from a Chau7 tab when they point at localhost; the Rust injection must run after that cleanup.

**Ports.** HTTP `127.0.0.1:<port>` (default 18080), TLS `127.0.0.1:<port+1>` (default 18081). Both bind loopback only. OpenAI goes through TLS so subscription Codex can upgrade to WSS; Anthropic and Gemini use plain HTTP.

**Certificate trust.** The proxy creates its loopback certificate in each app's owned Proxy data directory. Trust is not installed automatically: Swift does not add it, while Chau7 Next offers explicit Trust Certificate, Check Trust and Remove Trust controls for the user's login-keychain trust settings (the system prompts for a password; removing trust leaves the certificate in the keychain). The Codex wrapper also sets `CODEX_CA_CERTIFICATE` to the local certificate, or creates a private per-tab bundle combining it with an existing `CODEX_CA_CERTIFICATE`/`SSL_CERT_FILE`. If its owned endpoint or certificate is unavailable, the wrapper runs Codex without proxy routing.

**Proxy HTTP API** (proxy `main.go`, `task_endpoints.go`): `GET /health` -> `{"status":"ok"}`; `GET /stats` -> `calls_today, input_tokens_today, output_tokens_today, cost_today, avg_latency_ms`; `GET /task/candidate?tab_id=` -> `has_candidate, candidate_id, suggested_name, trigger, grace_remaining_ms, confidence`; `GET /task/current?tab_id=` -> `has_task, task_id, task_name, state, total_calls, total_tokens, total_cost_usd, duration_sec, start_method, trigger, project_path, baseline_total_tokens, tokens_saved`; `POST /task/start {tab_id, task_name?, candidate_id?}` -> `{task_id, task_name}`; `POST /task/dismiss {tab_id, candidate_id}` -> `{dismissed}`; `POST /task/assess {task_id, approved, note?}` -> `{success}`. Also `/task/name` and `/events` (not used by Swift). Every other path is proxied upstream.

**IPC messages** (one JSON object per line on `proxy.sock`, proxy is the client). `{"type":"api_call","data":{session_id, provider (anthropic|openai|gemini), model, endpoint, input_tokens, output_tokens, latency_ms, status_code, cost_usd, timestamp (ISO 8601), error_message, tab_id?, project_path?}}`. Task events carry `data` with: `task_candidate {candidate_id, tab_id, session_id, project_path, suggested_name, trigger (manual|new_session|idle_gap|repo_switch), confidence, grace_period_seconds}`; `task_started {task_id, candidate_id?, tab_id, session_id, project_path, task_name, start_method (manual|auto_confirmed|user_confirmed), trigger}`; `task_candidate_dismissed {candidate_id, tab_id, dismiss_method, reason}`; `task_assessment {task_id, tab_id, session_id, approved, note, total_api_calls, total_tokens, total_cost_usd, tokens_saved?, duration_seconds}`. Unknown types are logged and ignored.

**Database** (`analytics.db`, created by the proxy): tables `api_calls (session_id, provider, model, endpoint, input_tokens, output_tokens, latency_ms, ttft_ms, status_code, cost_usd, timestamp, error_message, task_id, tab_id, project_path)`, `model_pricing`, `tasks`, `task_assessments`, `events`, `model_output_stats`. Swift only reads `api_calls`; timestamps may have fractional seconds or not.

**Proxy defaults the Swift app does not override:** idle timeout before suggesting a new task 30 min (`CHAU7_IDLE_TIMEOUT`), candidate grace period 5 s (`CHAU7_CANDIDATE_GRACE_PERIOD`), baseline estimation on (`CHAU7_ENABLE_BASELINE`). `CHAU7_AETHYME_*` and `CHAU7_MOCKUP_*` exist in the proxy but are never set by the app.

**Correlation.** Next shell integration refreshes session/tab/project identifiers and Anthropic attribution headers after cwd changes; OpenAI-compatible base URLs carry project identity in the path. The shared Go proxy consumes the Anthropic headers. Codex subscription traffic uses the dedicated wrapper and local TLS/WSS route from PRX-021; the wrapper encodes project identity in the URL path, which the Go proxy converts to `X-Chau7-Project`. Codex does not carry Session/Tab headers in either app's current wrapper. Source and fake-fixture tests cover routing setup; they do not establish a live subscription-provider transaction.

**Settings keys** (UserDefaults, also in the settings export JSON): `analytics.api.enabled` (false), `analytics.api.port` (18080), `analytics.api.logPrompts` (false), `analytics.api.includeOpenAI` (true). Settings changes post `apiAnalyticsSettingsChanged`; the proxy posts `proxyStatusChanged`; calls post `apiCallRecorded`.

**Unused views.** `TaskCandidateToast` and `TaskStatusIndicator` (in the task view files) are not placed anywhere; not listed as features.

**What it records (privacy text shown to the user):** metadata only (model, tokens, latency, cost, status, endpoint), forwarded with auth headers unchanged; Chau7 stores no API keys. Prompt previews only with PRX-008. Data stays local.
